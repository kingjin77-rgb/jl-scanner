# ⚖️ JL 스캐너 — 법무법인 선정 공고 자동 탐지

네이버 카페에서 법무법인 선정공고를 자동으로 탐지·수집하는 도구입니다.

## 사용법
1. 사이드바에 **네이버 API 시크릿 키** 입력
2. 검색할 아파트명 입력
3. 스캔 시작

## 필요 키
- 네이버 개발자센터 API (Client Secret)
